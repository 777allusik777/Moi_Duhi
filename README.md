# Мои духи

Веб-приложение для учёта коллекции парфюмерии. Проект помогает хранить ароматы, структурировать органайзеры, фиксировать нанесения по датам, анализировать статистику и подбирать рекомендации по погоде и сезону. Все данные хранятся локально и не завязаны на внешние сервисы.

## Возможности

- Управление профилями и личной коллекцией
- Органайзеры с сеткой и сотами
- Карточки ароматов с фото, брендом, заметками и тегами
- Drag & Drop для перемещения ароматов внутри ячеек
- Календарь нанесений и история использования
- Статистика по брендам, сезонам, нотам и популярности
- Рекомендации на основе погоды и времени года
- Локальное хранение данных в JSON и файловой структуре проекта

## Технологический стек

- Frontend: React, TypeScript, Vite
- Backend: NestJS, TypeScript
- Общие типы: shared package
- Хранилище: локальные JSON-файлы и файлы изображений
- Внешний сетевой вызов: только парсинг Fragrantica для названия и фото

## Требования

- Node.js LTS 18+
- npm
- Windows 10/11 или macOS

## Быстрый запуск

### Windows — через готовый запускной файл

1. Установите Node.js LTS, если он ещё не установлен.
2. Перейдите в папку проекта `HUB`.
3. Запустите файл `run-project.bat`.

```bat
cd /d "C:\Users\<your-user>\path\to\HUB"
run-project.bat
```

Файл сам:
- проверит наличие зависимостей;
- запустит `install-npm.bat`, если нужно;
- запустит backend и frontend в отдельных окнах.

После запуска откройте:
- Frontend: http://localhost:5173
- Swagger: http://localhost:3000/api/docs

### Windows — ручной запуск

```bat
cd /d "C:\Users\<your-user>\path\to\HUB"
npm install
npm run dev:backend
```

Во втором терминале:

```bat
cd /d "C:\Users\<your-user>\path\to\HUB"
npm run dev:frontend
```

### macOS — через готовый запускной файл

1. Установите Node.js LTS, если он ещё не установлен.
2. Откройте терминал в папке проекта и выполните:

```bash
cd /path/to/HUB
chmod +x run-project-mac.sh
./run-project-mac.sh
```

Файл сам:
- проверит наличие Node.js и npm;
- установит зависимости при необходимости;
- соберёт `shared`, если это нужно;
- запустит backend и frontend в отдельных окнах Terminal.

После запуска откройте:
- Frontend: http://localhost:5173
- Swagger: http://localhost:3000/api/docs

### macOS — ручной запуск

```bash
cd /path/to/HUB
npm install
npm run dev:backend
```

Во втором терминале:

```bash
cd /path/to/HUB
npm run dev:frontend
```

## Локальные данные

По умолчанию проект хранит данные в папке `data` рядом с корнем проекта:

- `data/db.json` — профили, органайзеры, ароматы, календарь
- `data/images/` — изображения профилей и ароматов

Если нужно хранить данные в другом месте, задайте переменную окружения `DATA_DIR` перед запуском backend.

Windows:

```bat
set DATA_DIR=C:\MyData\Perfumes
npm run dev:backend
```

macOS/Linux:

```bash
export DATA_DIR=/path/to/your/data
npm run dev:backend
```

Очистка локальных данных:

```bash
npm run clear:data
```

## Стек реализации

- React + TypeScript + Vite — клиентский UI, страницы, модалки, интерактивные формы.
- NestJS + TypeScript — REST API, бизнес-логика, хранение и обработка данных.
- shared — общие типы и контракты между frontend и backend.
- Local JSON storage — хранение профилей, органайзеров, ароматов, календаря и изображений без внешней БД.
- Fragrantica parser — получение названия и фото аромата по ссылке.
- Open-Meteo — погодные рекомендации для подбора ароматов.
- Vitest + Playwright + Jest — валидация UI, интеграция и backend-проверки.

## Покрытие автотестов

- UI-тесты: проверка основных пользовательских сценариев на frontend.
- API-тесты: проверка REST-эндпоинтов и валидации данных backend.
- E2E-тесты: сценарии работы с коллекцией, календарём, органайзерами и профилями.
- Цель: покрыть критические пользовательские цепочки и устойчивость базовой логики приложения.
